Start the Brewfather Reports server

The Admin page needs the Brewfather Reports server, which isn't running at this address. In the Brewfather Reports folder run:

python app/server.py (or double-click start.bat, or use the Brewfather Reports desktop shortcut)

then open http://localhost:8642/admin.html.

Set up Brewfather Reports

Your Brewfather User ID and API key are stored only on this server. Create them in Brewfather › Settings › API with read access to batches and recipes (add write access to recipes if you'll send Next Brew recipes).

A key is already saved in .env. Leave both empty to keep it.

Standard recipe for imports

      
The Import recipe page rebuilds pasted recipes on this one: its equipment (batch size, efficiency, boil), mash, fermentation, water and usual yeast.

      

      
      

      

    

    

      
AI recipe reader (optional)

      
Lets the Import recipe page send a pasted recipe to an AI to read it, using your own API key and credit. Without it, recipes are read on this server and you answer a few questions instead.

      
      

        
        
        
      

      

      

      
The key is stored in .env on this server and is never shown again. The recipe text and your ingredient names are sent to the provider when you choose "Read it with…".
